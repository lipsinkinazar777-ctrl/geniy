# Алхимическая комната «Уголка принцессы Айсель»: UX/UI- и технический документ

Основа: твой ролик `Social_1.mp4` (5,08 с, 24 к/с, 720×1280, **без звуковой дорожки**) + то, что реально сделано в приложении (`src/js/potion.js`, `src/js/hands.js`, `tools/make_lab_plates.py`).
Везде, где написано «в ролике», это то, что видно в кадрах; «сделано» — что уже работает в сборке; «предложение» — что я рекомендую, но не делал.

## 1. Пользовательский сценарий (step-by-step)

### 1.1 Карта экранов

```
Главный зал (комната с камином)
  └─ «Книги» → Библиотека (ковёр, книги дугой)
        └─ дверца «Алхимия» → Алхимическая комната
              ├─ Состояние A: выбор настроений (котёл + полка склянок)
              ├─ Состояние B: варка (кино: рука с пустой склянкой)
              └─ Состояние C: результат (стол, склянка с ярлыком = книга)
                    ├─ «Открыть книгу» (если книга уже у неё) → Библиотека → читалка
                    ├─ «В «Хочу»» (если книга новая) → сохраняется на полку
                    └─ «Ещё раз» → обратно в состояние A
```

### 1.2 Раскадровка ролика (то, что мы воспроизводим)

| Время в ролике | Что происходит | Что делает камера / свет |
|---|---|---|
| 0,00–1,10 с | Термос-склянка стоит в кипящем зелёном котле, поднимаются светящиеся шарики, пар; слева из тьмы входит костлявая рука | Статичный средний план котла, зелёный свет снизу, свечи справа тёплые |
| 1,10–2,40 с | Рука берёт склянку, наклоняет, внутри склянки загорается свет | Медленный наезд, свет концентрируется вокруг склянки |
| 2,40–3,00 с | Рука вытаскивает заряженную склянку из зелья вверх | Камера следует за предметом |
| 3,00–3,30 с | **Склейка-«смаз»**: котёл уходит вверх, возникает стол | Быстрый наклон камеры, размытие |
| 3,30–3,90 с | Склянка опускается на дощатый стол среди бутылочек, свечей, книги; рука отходит влево | Статичный план стола, зелёный отсвет на досках |
| 3,90–5,08 с | Склянка стоит, из горлышка поднимается дымок; свечи мерцают | «Холд» на финальной композиции |

### 1.3 Сценарий в приложении (что видит и делает пользователь)

| # | Шаг | Действие | Реакция системы | Сделано |
|---|---|---|---|---|
| 1 | Вход | Из библиотеки тап по дверце «Алхимия» на сцене | Звон, плавное затемнение, комната-кадр проявляется из тьмы; поверх — заголовок «алхимия» и подсказка | да |
| 2 | Выбор | Тап по склянке-настроению на полке (уют, фэнтези, детектив, романтика, грусть, приключения), до 3 штук | Склянка вылетает по дуге, переворачивается, из неё в котёл льётся струя; всплеск, пузыри, **цвет зелья плавно перетекает** в смесь выбранных настроений | да |
| 3 | Сомнение | Тап по уже выбранной склянке | Снимается, цвет пересчитывается; четвёртая вытесняет первую | да |
| 4 | Запуск | Кнопка «Сварить зелье» (или тап по самому котлу) | Полка уезжает вниз, камера чуть наезжает, зелье закипает | да |
| 5 | Варка (≈4,3 с) | Пользователь только смотрит | Рука с пустой склянкой въезжает справа, склянка опускается в зелье, **наполняется** снизу вверх, светится, поднимается вверх за кадр | да |
| 6 | Склейка | — | «Смаз» вверх: котёл уходит, снизу въезжает стол | да |
| 7 | Результат | Смотрит; кнопки появляются через ≈0,6 с | Склянка встаёт на стол, вспышка яркости, дымок, пергаментный ярлык с названием книги, автором и настроениями; звон | да |
| 8 | Выбор дальше | «Открыть книгу» / «В «Хочу»» / «Ещё раз» | Переход в читалку / запись на полку («Добавлено ✓») / сброс в шаг 2 | да |

**Как подбирается книга** (`recommend()`): сначала её собственные книги со статусом «Хочу» — по совпадению настроений с тегами (3 очка за совпадение + малая случайность, порог 1,5); если ничего не подошло — каталог рекомендаций, без уже имеющихся. Результат всегда есть, пустого экрана не бывает.

**Правила юзабилити, заложенные в сценарий:** ни одного обязательного жеста длиннее тапа; нельзя «сломать» состояние повторными нажатиями (кнопки выключаются, `mode` не даёт войти в варку дважды); любая склянка пересчитывает цвет сразу; назад из любого состояния — системная кнопка «Назад».

## 2. VFX и атмосфера

### 2.1 Принцип: «кино на фотопластинах + живой слой сверху»

Сцены — это два кадра твоего ролика (котёл, стол), из которых **убраны термос и рука** (inpainting OpenCV, `tools/make_lab_plates.py`), поэтому на них можно честно рисовать своё. Поверх лежит один canvas 2D с частицами. Это даёт кино-качество фона при нулевой стоимости 3D.

Цвет зелья меняется **без перерисовки сцены**: для каждого настроения заранее сделана своя версия кадра (селективный сдвиг оттенка вокруг 125°: зелёное меняется, свечи и дерево остаются тёплыми). Версии лежат стопкой в DOM; смесь — это кросс-фейд непрозрачностей (1, 1/2, 1/3), то есть цвет считает GPU.

### 2.2 Свет

| Источник | В ролике | Как делаем |
|---|---|---|
| Зелье | Основной свет сцены, пульсирует | Радиальный градиент поверх котла, `lighter`; альфа = (0,03 + 0,06·жар)·(0,88 + 0,1·sin 2,4t); при варке жар → 1,2 |
| Свечи | 6 штук на каждом кадре, тёплые | Спрайты-ореолы в известных точках кадра (`CANDLES`), мерцание = сумма двух синусов с разными частотами и фазами на каждую свечу + «дыхание» радиуса |
| Склянка на столе | Зелёный отсвет на досках | Два градиента: вертикальное свечение вокруг склянки и сплюснутый эллипс (×0,22) на столе под ней — отсвет на дереве |
| Каменные стены | Едва видны на границе света | Виньетка и затемнение по краям (CSS), без отдельной подсветки: свет не должен «лизать» стены сильнее, чем в исходнике |

### 2.3 Частицы (Canvas 2D, спрайты кэшируются)

| Система | Параметры | Зачем |
|---|---|---|
| Пар над котлом | спавн 7–19/с (зависит от жара), жизнь 3–5,4 с, размер 46–92 px → ×2,5, обычное смешивание, α ≤ 0,35 | Основной «объём» сцены. Рисуется шумовыми «клочьями» (4 варианта на цвет, кэш), а не круглыми размытыми пятнами; размер клочьев ограничен (×1,45 к экрану), чтобы на широких экранах пар не закрывал комнату |
| Парящие шарики | спавн 4–16/с, жизнь 2,4–4,8 с, r 2–6 px, дрейф по синусу | Как светящиеся шарики в ролике: кольцо + 22 % заливки + блик |
| Пузыри | 7–47/с (по жару), лопаются волной-кольцом | Кипение; лопнувший пузырь рождает кольцо ряби (эллипс 1:3,8) и иногда звук |
| Капли и рябь при переливании | 3 капли каждые 30 мс, гравитация 620 px/с² | Склянка действительно «льётся», а не телепортируется |
| Дымок над склянкой на столе | 11/с, подъём 22–44 px/с, рост ×5,4 | Финальный «холд» ролика |
| Всплеск при погружении | 30 пузырей + 3 кольца | Сопровождает касание склянкой поверхности |

Все массивы фильтруются на месте (без `new` в кадре, кроме объектов частиц), `dt` ограничен 50 мс, при скрытой вкладке цикл спит.

### 2.4 Камера и склейка

* Наезд на варке: `cam.z` 1 → 1,1 по экспоненте (скорость 1,6/с), точка наезда — центр жидкости (55 % высоты экрана).
* «Смаз» между котлом и столом: уходящий кадр `translate −90px + blur(12px) + fade` за 0,9 с, приходящий — `translate +100px + blur → 0`; поверх мгновенно проходит чёрная вуаль с пиком 55 % (имитация размытия движения). Это повторяет наклон камеры из ролика на 3,0–3,3 с.
* Ландшафт: кадр «обрезается» по высоте экрана (`cover`), точка фокуса смещена так, чтобы жидкость и склянка всегда были в кадре; полка склянок уменьшается.

### 2.5 Дисциплина слоёв (важно)

В тестовом Chromium без GPU (SwiftShader) пустой **полноэкранный** `position:fixed` слой поверх сцены ломал композитинг и затемнял её. Корневой слой рук теперь нулевого размера (`width:0;height:0`), а дети позиционируются относительно него — визуально ничего не изменилось, артефакт исчез. Правило для разработки: **не держать пустых экранных слоёв**.

## 3. Интерактивные состояния, триггеры и звук

### 3.1 Конечный автомат

```
            ┌────────────┐  tap vial (≤3)   ┌──────────────┐
  show() →  │   PICK     │ ───────────────→ │ PICK (mixing)│ ┐ повтор до 3
            └─────┬──────┘                  └──────┬───────┘ ┘
                  │ tap «Сварить» / tap котёл (sel≥1)
                  ▼
            ┌────────────┐  ~4,3 с  ┌──────────────┐  ~1,9 с  ┌────────────┐
            │   BREW     │ ───────→ │  WHIP → стол │ ───────→ │  RESULT    │
            └────────────┘          └──────────────┘          └─────┬──────┘
                                                                    │ «Ещё раз» → PICK
```

| Состояние | Что кликабельно | Заблокировано | Выход |
|---|---|---|---|
| PICK | 6 склянок (hit-area ≈ 74×110 px), котёл (эллипс жидкости ×1,1/×3 по вертикали), «Сварить» | — | BREW |
| BREW | ничего (кроме «Назад») | всё, повторный запуск | RESULT |
| RESULT | «Открыть книгу» / «В «Хочу»» / «Ещё раз», склянка (подсветка) | котёл | PICK или другой экран |

Каждый асинхронный шаг варки проверяет токен (`token`): если пользователь вышел из комнаты, шаги тихо прекращаются — никаких «призрачных» звуков и склянок в чужих экранах.

### 3.2 Триггеры и реакции

| Триггер | Реакция (визуал + звук + вибрация) |
|---|---|
| Тап по склянке | Вибро 10 мс, «пузырь», полёт по дуге 0,76 с, струя 0,65 с, на 380 мс — смена цвета, рябь, +24 пузыря, второй «бульк» |
| Тап по «Сварить» без выбора | Тост «Выбери настроение», сова, вибро 20 мс — человек понимает, что делать |
| Котёл | то же, что кнопка (большая цель: пальцу не нужно целиться в кнопку) |
| Погружение склянки (1,45 с) | Рябь + 30 пузырей, «бульк» |
| Склянка поднимается (3,1–3,9 с) | Включается свечение `pv--lit` (drop-shadow цвета зелья) |
| Склейка | Звук «вжух» |
| Постановка на стол | Вспышка яркости 240 % → 100 % за 0,9 с, аккорд, вибро 24 мс |
| Полки с книгами/ингредиентами на стене | **Предложение, не сделано:** в ролике на заднем плане полки с бутылками и пучки трав; их можно сделать «подсказками» (тап → название ингредиента/настроения), но тогда нужны отдельные хит-области в системе координат пластины |

### 3.3 Звуковой дизайн

Ролик беззвучный, поэтому звук проектируется с нуля. В приложении всё синтезируется в WebAudio (`src/js/audio.js`), файлов нет, загрузки нет. Ниже честно разведено: что **уже играет** и что **предлагается добавить** (это отдельная работа, я её не делал).

**Что играет сейчас** (одноразовые звуки, привязанные к событиям):

| Момент | Звук | Из чего собран |
|---|---|---|
| Тап по склянке | «бульк» (`bubble`) | короткая синусоида 180–480 Гц с падением высоты ×2,2 |
| Склянка опрокинулась, на 380 мс | второй «бульк» + рябь | то же |
| Запуск варки | `brew` | полоса шума 600 → 3200 Гц (1,8 с) + арпеджио из 6 нот (D4–A5, треугольная волна) |
| Погружение склянки (1,45 с) | «бульк» + 30 пузырей на экране | `bubble` |
| Лопание пузыря | редкий `bubble` (12 % лопаний) | чтобы кипение слышно, но не трещало |
| Склейка котёл → стол (≈4,3 с) | «вжух» (`whoosh`) | полосовой шум 260 → 2400 Гц + две ноты |
| Постановка на стол | аккорд (`chime` 523/659/783/1046 Гц) | синус + октава треугольником, хвост 1,2 с |
| Пустой запуск без выбора | сова | две ноты 392/349 Гц |

**Чего сейчас нет, но ролик просит** (предложение, звуковая карта):

| Звук | Привязка | Рекомендация |
|---|---|---|
| Непрерывное бульканье | с входа, громче при `жар` | петля 4–6 с: шум 180–600 Гц, случайные всплески; −24 → −14 дБ |
| Шипение пара | 0–4 с варки и дымок на столе | шум high-pass 2–4 кГц, медленный LFO; −30 дБ |
| Мистический гул | от погружения до подъёма склянки | 2–3 синуса (110/164/220 Гц) с лёгкой расстройкой; нарастает вместе со свечением склянки |
| Стук стекла о дерево | момент касания стола | короткий резонансный клик ≈1,8 кГц + низкий «тук» 120 Гц |

Правила: звук стартует только после первого касания (политика браузеров), уважает выключенный звук в настройках, настоящая запись (4–5 коротких Ogg ≈20 КБ каждая) была бы богаче синтеза.

## 4. Технические рекомендации

### 4.1 Стек: что выбрано и почему не React/Vue/Three.js

| Вариант | За | Против для этого проекта | Решение |
|---|---|---|---|
| **Vanilla JS + CSS + Canvas 2D** (текущий) | Сборка 614 КБ целиком, нет рантайма, нет зависимостей, оффлайн-PWA, мгновенный старт | Ручное управление состоянием | **Оставить.** Всё приложение — один набор комнат с общим роутером; состояние комнаты — одна переменная `mode` |
| React/Vue + Tailwind | Удобно для форм и списков | +40–130 КБ рантайма, виртуальный DOM не нужен там, где 90 % экрана — canvas и пластины; перезапись всего приложения | Только если команда вырастет и появится много «обычных» экранов; комнату всё равно оставлять отдельным модулем |
| PixiJS | Быстрые спрайты, фильтры, смешивание | +150 КБ; для 3–4 сотен частиц Canvas 2D достаточно | Рассмотреть при >1000 частиц или шейдерном паре |
| Three.js / WebGL | Настоящий объёмный пар, свет, стекло | +500 КБ, 3D-модели котла/склянки нужно делать с нуля, риск на слабых Android | Не для этой сцены. Если захочется «объёмного» пара — отдельный фрагмент-шейдер в одном WebGL-canvas, а не вся сцена |
| Видео (mp4/webm) | Максимальное качество кадра | Нельзя менять цвет под настроение, нельзя связать с выбором пользователя; ≈4 МБ на клип | Только для входа (уже так) |

### 4.2 Производительность (мобильные и ноутбуки)

Бюджет: 60 к/с на iPhone 11+, 30 к/с стабильно на Android среднего класса.

* **Пластины:** 1080×1920 WebP (кадр ролика 720×1280, увеличенный в 1,5 раза с мягким усилением резкости; рисуются как 720×1280 css-пикселей, поэтому на ретине резче), ~55 КБ каждая (14 штук ≈ 770 КБ). В памяти ≈8 МБ на растровую текстуру; 14 штук в стопке ≈110 МБ — **для слабых устройств скрывать (`display:none`) версии с нулевой прозрачностью** и держать в DOM максимум 3 одновременно видимых (сделано через непрозрачность; следующий шаг — `display:none` после завершения кросс-фейда).
* **Слои:** не более ~10 композитных слоёв на экран; пустых полноэкранных слоёв нет (см. 2.5); `will-change` только на пластинах и руках.
* **Canvas:** один на сцену, размер = экран × `min(devicePixelRatio, 2)`; сейчас 1×, частицы мягкие и не требуют резкости; спрайты (`blob`) рисуются один раз в `128×128` и переиспользуются (`spriteCache`), сбрасываются только при смене смеси.
* **Цикл:** один `requestAnimationFrame`, `dt = min(dt, 50 мс)`; цикл спит при `document.hidden` и когда комната скрыта; частицы без аллокаций сверх объекта.
* **Режим «лёгкий»:** если средний кадр >24 мс 2 с подряд — вдвое меньше спавна частиц и без `lighter`-градиентов (предложение, не сделано).
* **Сеть/кэш:** все пластины в precache сервис-воркера (`sw.js`, версия по хэшу сборки); картинки комнаты создаются при старте приложения, поэтому вход в комнату мгновенный (цена — ≈350 КБ при первой загрузке; можно отложить до первого захода в библиотеку).
* **Анимация:** только `transform` и `opacity` на DOM, всё остальное — в canvas; нет анимации `width/height/top/left` и тяжёлых `filter` на крупных слоях (blur только на уходящей пластине 0,9 с).
* **Доступность:** `prefers-reduced-motion` → без смаза, без наезда, частицы ×0,3 (предложение); все кнопки — `<button>` с `aria-label`; цель касания ≥44 px.

### 4.3 Структура кода

```
src/js/potion.js     комната целиком: build / layout / pick / brew / whip / setTable / draw*
src/js/hands.js      спрайтовые руки: reach / grasp / page / carry (+ пружины)
tools/make_lab_plates.py   кадры из ролика → пластины → перекраска по настроениям
src/css/50-lib.css   стили .pz*, .pzv*, .pv* (склянка), .pz__tag
```
Порядок конкатенации задаётся в `tools/build.py`; одна точка входа `A.mods.potion` (`show/hide/rebuild`).

### 4.4 Что честно не идеально

* Рука — **2D-спрайт** (фото руки в нескольких позах), а не 3D; в ролике рука костлявая ведьмина — она убрана с пластин и заменена нежной рукой героини, потому что приложение женское, а не хэллоуинское.
* Исходные кадры ролика — 720×1280; на больших экранах они растягиваются и слегка мягкие; для «ретины» нужна пересъёмка ролика в 1080×1920.
* На пластинах остаётся лёгкая дымка там, где был термос; её перекрывает склянка и пар, но при рассматривании вплотную заметно.
* Звук синтетический; настоящая запись булькания и гула была бы богаче (4–5 коротких файлов Ogg по ≈20 КБ).
