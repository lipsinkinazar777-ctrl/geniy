# Maison Volodymyr: премиальный сайт

Статический сайт (HTML/CSS/JS, без сборки). Запуск: `python3 -m http.server -d maison 8000` и открыть http://localhost:8000.

## Что внутри
- `index.html`, `css/style.css`, `js/main.js`: сайт целиком (язык: французский).
- `assets/`: картинки. Герой собран из слоёв, отрендеренных **с одной камеры**, поэтому они совпадают пиксель в пиксель:
  - `hero-bg.jpg`: сцена (градиент, камни), `hero-scene.jpg`: она же с кружкой, единая картинка (превью/og:image)
  - `hero-mug.webp`: кружка отдельным слоем с альфой и тенью
  - `hero-box-base.webp`, `hero-box-lid.webp`: закрытая коробка с золотой лентой (основа и крышка)
  - `card-*.webp`: картинки для плашек и каталога; `print-bmw.jpg`: принт кружки на входе
- `tools/`: рендер (Three.js в headless Chromium) и проверки.

## Reveal на кружке
Коробка закрыта. При наведении (на телефоне касание) крышка улетает, кружка выезжает из-за стенки, коробка растворяется. Это чистый CSS по классу `.is-open` (`.layer--lid / --base / --mug` в `style.css`).

## Заменить картинки на Higgsfield
Положить файлы с теми же именами в `assets/`:
1. `hero-bg.jpg` (2560×1600): сцена **без** товара.
2. `hero-mug.webp`: кружка с прозрачным фоном и тенью, тот же кадр, что в п.1.
3. `hero-box-base.webp` + `hero-box-lid.webp`: закрытая коробка, разрезанная на основание и крышку, тот же кадр.
Если пропорция/позиция товара в кадре изменится, подправить переменные `--mt`, `--mh` (верх и высота кружки в долях сцены) в `.hero` в `style.css`.

## Перерисовать рендеры
```
cd maison/tools && npm i && ./hero.sh && ./cards.sh
```

## Проверки
`node tools/selfcheck.mjs`: hero-reveal, корзина, сумма со скидкой, ссылка WhatsApp, клавиатура, мобильная версия, ошибки консоли.

## Шрифт
Neue Haas Grotesk Display лицензионный, в репозиторий не положен. Если он установлен, используется он; затем Helvetica Neue (почти он же), затем Inter Tight. Чтобы подключить свой файл: добавить `@font-face { font-family: "Neue Haas Grotesk Display Pro"; font-weight: 300; src: url(../fonts/NeueHaasDisplay-Light.woff2) }`.

## Нужно подтвердить
- Цены взяты из листка (`launch/whatsapp_quick_replies.txt`, `coffrets/generate_bordeaux.js`). Допущения: porte-clés «двойной» = 5 € (из состава коффрета), «простой» = «dès 2 €».
- «Photo sur métal»: размеры и цены 4/6/8/25 € взяты из строки «Photo» прайса.
- Фото на карточках (семья, Париж, горы) нарисованы процедурно, это заглушки для замены реальными работами.
