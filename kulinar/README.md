# Гений кухни — кулинарная академия

Один HTML-файл (`index.html`) без сервера: рецепты, курс повара из пяти уровней, школа (плита 0–9, нарезка, жарка, масло, варка, безопасность, стейки), знания (пасты, мясо, соусы, крупы, специи, картофель, пицца), здоровье (питание, калории), покупки (приборы с чекбоксами «есть/хочу», ножи, хранение специй, закупки на двоих), планер недели и «🎲 случайное блюдо».

Данные пользователя (избранное, «я научился», уроки, тесты, приборы, планер, дневник калорий) хранятся в `localStorage` браузера.

## Структура

```
kulinar/
  index.html            # собранный файл (генерируется)
  src/
    00-head-open.html, 90-head-close.html   # каркас страницы
    style1.css, style2.css, style3.css      # стили
    js/10…19-*.js       # рецепты (R(...)), справочники фото-запросов (PQ)
    js/20…29-*.js       # энциклопедия, академия, коллекции, фото-источники
    js/30-core.js       # роутер, хабы, фото, анимации, плавный скролл, поиск
    js/4x…7x-*.js       # разделы: школа, знания, здоровье, покупки, курс, планер, главная
    img/                # фото блюд (имя файла = id рецепта, gear-… для приборов)
  tools/
    build.py            # сборка index.html
    fetch_photos.py     # скачивание фото из Википедии/Commons/TheMealDB
    tests/*.js          # проверки в Playwright
```

## Сборка

```bash
python3 kulinar/tools/build.py             # фото вшиваются в один файл (бюджет 12 МБ)
python3 kulinar/tools/build.py --external  # фото лежат рядом в kulinar/img/
```

## Фото блюд

Положите свои снимки в `src/img/<id>.webp|jpg|png` (id рецепта — см. `R('id',…)` в `src/js/1x-*.js`).
Остальные можно скачать автоматически (нужен интернет):

```bash
python3 kulinar/tools/fetch_photos.py --list     # что будет скачано
python3 kulinar/tools/fetch_photos.py --build    # скачать недостающее и пересобрать
python3 kulinar/tools/fetch_photos.py --sheet    # контактные листы для просмотра (Pillow)
```

Если фото нет в `src/img`, приложение пробует подтянуть его из Википедии прямо в браузере (нужен интернет), иначе показывает эмодзи на цветном фоне. Источники и лицензии — в разделе «Источники фото» (`#/credits`).

## Проверки

```bash
cd kulinar/tools/tests && npm i playwright   # один раз
node check_routes.js   # данные (id, коллекции) + открытие всех страниц и вкладок
node check_clicks.js   # меню, поиск, случайное блюдо, планер, приборы, тесты, мобильная версия
```
